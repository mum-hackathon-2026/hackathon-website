Security & Best Practices Averis X Monash Hackathon 2026

Secrets & Environment Variables

Protect your OpenAI keys, database passwords, and client credentials.

⛔ What NEVER to do
  • 1. Never commit .env to GitHub: Public bots scan GitHub in milliseconds and revoke or exploit leaked keys.
  • 2. Never put secret API keys in Frontend code: Anything prefixed with NEXT_PUBLIC_ or in Angular/React is shipped directly to the browser.
  • 3. Ensure .gitignore includes: .env, .env.local, credentials/*.json.
✅ The Right Way (Vercel Secrets)
  • 1. Use Vercel Project Environment Variables: Set your keys securely in Project Settings ➔ Environment Variables.
  • 2. Commit .env.example: Provide placeholder dummy keys so teammates know which configs are needed.
  • 3. Separate Environments: Define different keys for Production vs. Preview (Branch PRs).
Presenter: Shariq Nauman Slide 6 / 14
Warn teams about leaked API keys on GitHub. Bots scrape repositories and drain OpenAI or cloud credit balances within minutes.

Team Workflow Averis X Monash Hackathon 2026

Preview Branches & Team Collaboration

Test new features safely without breaking the main presentation link.

How Branch Previews Work

  1. Team member creates a branch: git checkout -b feat/ocr-results
  2. Make changes and push to GitHub repository.
  3. Open a Pull Request on GitHub.
  4. Vercel Bot instantly comments on the PR with a unique live staging URL (e.g., yourapp-git-feat-ocr.vercel.app).

Why This Wins Hackathons

  • ✓ Zero Merge Conflicts on Main: Main branch stays rock solid for demo judges.
  • ✓ Instant Visual Feedback: Teammates test UI features on their own phones immediately.
  • ✓ Rollback Safety: If a merge fails, rollback to any previous commit in 1 click.

API Integration Averis X Monash Hackathon 2026

Connecting Backend APIs & CORS

Bridging the deployed Vercel frontend with Cloud Run backend services.

⚠️ The #1 Bug: CORS Blocked

Browser blocks API requests from *.vercel.app to backend unless CORS headers are explicitly sent by the backend.

Access to XMLHttpRequest at '...' from origin 'https://app.vercel.app' has been blocked by CORS policy.

✓ The 2-Minute Solution

Configure backend CORS to allow your Vercel domains:

# FastAPI Python:

app.add_middleware(CORSMiddleware,

allow_origins=["*"], allow_methods=["*"])

# Express Node.js:

app.use(cors({ origin: '*' }))

Presenters: Darren & Shariq Slide 11 / 14
Remind participants that setting allow_origins in development allows rapid testing, but specify production origins before final submission if handling sensitive tokens.
Troubleshooting Guide Averis X Monash Hackathon 2026

Top 5 Hackathon Pitfalls & Instant Fixes

Bookmark these solutions before hackathon submission weekend.

01. SPA 404 Refresh

Direct URL navigation returns 404.

vercel.json rewrite to /index.html
02. Mixed Content

Calling http:// API from HTTPS Vercel.

Always use HTTPS backend
03. Missing Env Var

Undefined API config breaks client build.

Re-deploy after adding var
04. Hardcoded Host

API fetch still calls localhost:8080.

Use process.env.API_URL
05. Node Version

Engine mismatch on package dependencies.

Set Node 20.x in settings

Final Deliverables Averis X Monash Hackathon 2026

Submission Day Readiness Checklist

Verify these 4 points before locking your submission form.

📱

1. Test on Incognito & Mobile Phone

Open your live Vercel URL on 4G/5G on a smartphone and in private browser mode to verify no local cookies or session dependencies are required.

🔑

2. Demo Credentials Pre-filled

If your project has authentication, provide a 1-click "Guest Demo Login" button or put sample test credentials directly in your GitHub README.

📹

3. Screen Recording Backup

Record a 3–5 minute Loom / YouTube walkthrough of your live app working. If an upstream AI API rate-limits during judging, your backup video protects your score.

📂

4. GitHub Repo Public & Documented

Ensure the repository is set to Public, includes clean setup steps, and links to your live Vercel deployment prominently at the top of the README.
