Security Rules

Environment Variables & Secrets

Never Commit API Keys

🚫 The Critical Mistake

Pushing an OpenAI key, Groq key, or DB password to a public GitHub repo can get your key revoked in 60 seconds by automated GitHub secret scanners.

# .gitignore
.env
.env.local
node_modules/

✅ The Proper Cloud Workflow

Keep `.env.example` in your repo with blank placeholder values for your teammates. Add real credentials directly into the Vercel Project Settings dashboard.

• GROQ_API_KEY = gsk_xxxxx (Server only)

• NEXT_PUBLIC_API_URL = https://... (Public)

Troubleshooting Guide

Top 3 Deployment Pitfalls

Fix before submission
01

CORS Blocked

Frontend on Vercel cannot talk to backend on Render because backend doesn't allow cross-origin requests.

Fix: allow origin *.vercel.app
02

Hardcoded Localhost

Frontend code contains http://localhost:8080/api, which fails on any external computer or phone.

Fix: use process.env.API_URL
03

Build Step Errors

TypeScript or linter errors pass in dev mode but crash during npm run build in CI.

Fix: test npm run build locally
